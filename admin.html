Connect your store

The admin panel needs a free Supabase project to save products and photos. The site is showing sample products until it's connected.

  1. Create a project at supabase.com.
  2. Run supabase/setup.sql in its SQL Editor.
  3. Paste the project URL and publishable key into assets/js/config.js.
  4. Create your admin user, then come back to this page.

The full steps are in README.md.
